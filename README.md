# FOLLOWERS для DLE 21

Адаптивный тёмный шаблон для блога и онлайн-журнала на DataLife Engine. Коралловые акценты, слайдер публикаций, карточки новостей и боковая колонка.

**Версия адаптации:** 1.0.0. Совместимость проверена с **DLE 21.0 и PHP 8.3**. Шаблон имеет только тёмную тему.

[Скачать релиз](https://github.com/The88788/FOLLOWERS-DLE21/releases/latest) · [Описание и скриншоты](https://the88788.com/files/dle/templates/dle21/136-followers-dle-21.html)

## Возможности

- Адаптивная вёрстка для компьютеров, планшетов и телефонов.
- Слайдер до пяти последних публикаций на первой странице главной.
- Карточки новостей, обложки, категории, теги и штатная пагинация DLE.
- Меню и поиск с поддержкой клавиатуры и закрытием по Escape.
- Комментарии, закладки, профиль и диалоги личных сообщений.
- Оформление регистрации, обратной связи, статистики и добавления новости.
- Отдельная страница технических работ.
- Локальные шрифты иконок и JavaScript без Owl Carousel, Isotope и Bootstrap JS.

## Установка

1. Сделайте резервную копию текущего шаблона и настроек сайта.
2. Скачайте ZIP из [релиза](https://github.com/The88788/FOLLOWERS-DLE21/releases/latest).
3. Скопируйте папку `followers` в каталог `templates` установленного DLE 21.0.
4. Выберите `followers` в настройках сайта, очистите кеш DLE и обновите страницу браузера.
5. Если сайт установлен в подкаталог, проверьте базовый URL в настройках DLE. Работа шаблона в подкаталоге проверена.

Подробная инструкция `INSTALL.md` находится в архиве релиза. Ядро CMS и демонстрационная база данных в поставку не входят. Рядом с ZIP в релизе опубликован файл `SHA256SUMS.txt` для проверки целостности архива.

### Обложки и содержимое

Для обложек можно использовать дополнительное поле `poster` типа «Изображение». Оно необязательно: без него используется первое изображение краткой новости, затем резервная картинка.

Категории, теги, количество новостей, права групп, редакторы и способы регистрации настраиваются штатными средствами DLE. Для работы шаблона дополнительные серверные модули не требуются.

## Структура шаблона

| Файл | Назначение |
| --- | --- |
| `followers/main.tpl` | Каркас страницы и подключение ресурсов |
| `followers/header.tpl`, `footer.tpl`, `sidebar.tpl` | Шапка, футер и боковая колонка |
| `followers/shortstory.tpl`, `fullstory.tpl` | Карточка и полная публикация |
| `followers/partners.tpl` | Блоки услуг по DLE и VPS-хостинга |
| `followers/css/style.css` | Основное оформление и компоненты DLE |
| `followers/js/custom.js` | Меню, поиск, слайдер и прокрутка |
| `followers/offline.tpl`, `css/offline.css` | Страница технических работ |

`editor.css`, `frame.css`, `preview.css` и служебные TPL подключаются DLE в соответствующих разделах. Не удаляйте их на основании того, что они не загружаются на главной странице.

## Проверки и ограничения

Проверены адаптивность на ширинах 320, 390, 820, 1366 и 1920 px, меню, поиск, слайдер, пагинация, авторизация, основные формы, редакторы, комментарии, профиль и личные сообщения. Пути проверены с другим именем папки шаблона и при установке DLE в подкаталог.

Другие версии DLE не заявляются. Внешняя доставка почты, OAuth-провайдеры, внешняя CAPTCHA и отправка файлов через пользовательскую форму не проверялись. Их работа зависит от настроек CMS, прав и лимитов сервера.
